# Agent Instructions

- Be concise and to the point. No "thinking out loud" in responses.
- Never attribute AI in commits (no Co-Authored-By, no mentions of Claude/AI in commit messages).
- Write tests where possible.
- Design code so it is easy to write tests for.
- Always run tests to validate your work.
- Always lint your code with repo rules and fix lint issues.
- Do feature work in feature branches.
